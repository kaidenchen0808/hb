# 设计:对话框千问范式重构（深色文档流 / 输入卡片化 / hover 工具条）

- 日期:2026-10-27
- 状态:设计已确认(brainstorm 逐段过审),实现中
- 范围:纯 app 侧(ChatView 重排 + MarkdownView 微调),0.15.0 单版本交付
- 决策基调:**B — 保持深色主题,只改交互范式**(Cursor/Copilot Chat 是深色文档流的优秀样板,不推翻配色)

## 范式一:消息流重构

- **AI 消息去气泡**:删半透明底色块,Markdown 全宽文档流直渲(代码块/表格/公式等内部元素自带深色圆角卡 →"文档嵌卡片"层次,千问同款);24pt sparkles 头像保留
- **用户消息**:右侧蓝气泡不变(13pt 紧凑)
- **思考折叠条轻量化**:"已深度思考 · 用时 N 秒 ▾"细条(11pt 次级灰、无底色);用时 = thinkingText 首末增量时间戳差;流式中"思考中…"带脉冲点
- **hover 工具条**:AI 消息底部 hover 浮现小图标行(复制/重生成/删除),取代 timestamp 行散置按钮

## 范式二:输入区卡片化(豆包同款)

- 整个输入区收进一张大圆角卡片(r16 浅半透明底+细描边):
  - 附件缩略图横排卡片**内部顶部**(✕ 深色底圈)
  - 多行输入居中
  - 底部工具行:📎 / 🎤 / 深度思考开关 / 圆形发送按钮(输入时蓝亮、流式变 ■ 停止)
- lookup 指示条保持卡片上方(全局状态)
- `/` 技能面板从卡片顶部上浮
- placeholder 引导:"给她说点什么…(/ 选技能 · ⌘V 贴图 · Shift+Enter 换行)"

## 范式三:浮标与密度

- **回到底部浮标**:离底 >1 屏右下角浮现 ↓ 圆钮;新消息到达且不在底时带红点
- 密度:AI 文档流 14pt/1.6 行高/消息距 20pt;用户气泡 13pt;折叠条 11pt 灰

## 明确不做

浅色主题(基调 B)、会话列表、消息编辑、点赞点踩

## 测试与验收

- 构建+全量测试;纯 UI 重排无逻辑变化(现有测试全保留)
- 手测:AI 回复无气泡全宽渲染 / 代码块表格内嵌卡片感 / hover 工具条 / 折叠条用时显示 / 输入卡片一体的附件与工具行 / 回底浮标与红点 / 深色下整体密度观感
